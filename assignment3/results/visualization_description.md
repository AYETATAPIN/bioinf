# Визуализация пайплайна

В качестве фреймворка для пайплайнов используется Mage. В Mage пайплайн отображается как DAG: блоки являются узлами графа, а зависимости между блоками показывают порядок передачи данных и выполнения.

Для получения визуализации нужно:

1. Запустить Mage из папки `assignment3/mage_project`.
2. Открыть `http://localhost:6789`.
3. Выбрать pipeline `mapping_qc`.
4. Открыть graph/DAG view.
5. Сохранить скриншот как `assignment3/results/mage_pipeline_dag.png`.

Отличие DAG в Mage от блок-схемы в задании:

- Блок-схема из PDF описывает общий алгоритм и ветвление `OK/not OK`.
- DAG Mage показывает реальные исполняемые блоки проекта и их зависимости.
- В DAG не обязательно отображается каждая команда внутри bash-скрипта; часть команд сгруппирована в один исполняемый block.
- Ветка `OK/not OK` сохраняется в файле результата, а не рисуется как отдельный ромб принятия решения.
