# Mage project for Assignment 3

Run from `assignment3/`:

```bash
bash scripts/start_mage.sh
```

Open:

```text
http://localhost:6789
```

Pipelines:

- `hello_world` - minimal framework test
- `mapping_qc` - wrapper pipeline for the bash mapping-quality workflow

After opening `mapping_qc`, use the graph/DAG view and save a screenshot as:

```text
../results/mage_pipeline_dag.png
```
